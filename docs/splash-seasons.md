# Сезонное оформление React splash

Изменения относятся только к `components/SplashScreen.js`, а не к системному экрану запуска Android/iOS. Готовность приложения и длительность загрузки не меняются: оформление не добавляет таймеров ожидания и не блокирует переход в приложение.

## Выбор оформления

`utils/splashSeason.js` использует локальный месяц устройства (северное полушарие):

| Месяцы | Оформление |
| --- | --- |
| Декабрь–февраль | Снежинки |
| Март–май | Цветы/лепестки и листья |
| Июнь–август | Небольшие светлячки/солнечные искры, медленно поднимающиеся вверх |
| Сентябрь–ноябрь | Падающие осенние листья |

Это лёгкое декоративное оформление иконками Ionicons, а не физически реалистичные листья, снег или лепестки. Начальные фазы распределены по всей высоте краёв экрана: оформление видно и при коротком splash, без ожидания падения сверху. Фаза циклически переносится через границу с нулевой прозрачностью, скрывая скачок при перезапуске.

Переданный `holidayInfo` из существующего `getHolidayInfo()` имеет приоритет над сезоном. Даты не дублируются: утилита использует только тип праздника. Поддержаны все 16 текущих типов: Новый год, оба Дня студента, День святого Валентина, День защитника Отечества, 8 Марта, День космонавтики, 1 Мая, День Победы, День защиты детей, День знаний, 3 сентября, День программиста, День сисадмина, День преподавателя, День народного единства. Используются соответствующие Ionicons (сердца, цветы, книги, ракеты, серверы и т. д.); неизвестный тип получает нейтральные звёзды. Существующие поздравления и их цвета сохранены.

В Matrix и при разблокированной «Легенде» дополнительный сезонный/праздничный слой отключён, чтобы не конкурировать с существующим оформлением. Поздравление над логотипом остаётся.

## Доступность и производительность

- `AccessibilityInfo.isReduceMotionEnabled()` проверяется асинхронно; до ответа и при ошибке проверки показывается статичный экран с тремя неброскими декоративными значками, без частиц.
- При включённом Reduce Motion остаются статичные значки; отключены также дрейф блобов, пульсация, появление текста/логотипа и Matrix Rain. Системный индикатор загрузки остаётся.
- Подписка `reduceMotionChanged` переключает режим во время показа; поздний ответ первоначальной проверки не перекрывает новое значение события.
- При разрешённой анимации выводится не более 12 частиц по краям экрана. Используются только native-driver transform/opacity и неинтерактивные циклы, без новых зависимостей, сетевых запросов или JS-интервалов.
- Декоративный слой не перехватывает касания и скрыт от screen reader. Центральная область отведена логотипу и тексту.
- Анимации частиц и прежние splash-циклы останавливаются при размонтировании/смене режима. Подписка доступности снимается; обновление состояния после размонтирования запрещено.

## Проверка

Автоматически: `node --test tests/splashSeason.test.cjs` (границы сезонов, все праздничные типы, приоритеты, fallback и лимит частиц). Общий набор: `node --test tests/*.test.cjs`.

Ручная проверка в development-сборке:

1. Проверить светлую/тёмную тему с датами в январе, апреле, июле и октябре; логотип и текст должны оставаться читаемыми, частицы — неброскими.
2. Передать `holidayInfo` с каждым поддерживаемым типом и проверить замену сезонных частиц праздничными; текст поздравления не меняется.
3. Проверить Matrix и «Легенду»: дополнительного слоя нет, прежнее оформление сохранено.
4. Включить системное уменьшение движения до запуска и переключить во время splash: нет летящих частиц, дрейфа и пульсации; контент виден сразу. Проверить также отказ/задержку API доступности.
5. Быстро закрыть splash/перезапустить приложение: нет предупреждений об обновлении после размонтирования и оставшихся циклов. Поворот/изменение размера окна корректно меняет границы слоя.
6. Убедиться, что быстрый запуск не ждёт завершения анимации и не стал дольше.

Визуальные проверки Android/iOS требуют устройства/эмулятора; проверки утилит и синтаксиса их не заменяют.
