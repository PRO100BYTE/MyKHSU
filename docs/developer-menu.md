# Меню разработчика

`DeveloperMenuScreen` использует единое оформление настроек: заголовки секций и группы с радиусом 14, межсекционные отступы 16, шрифты Montserrat и интерактивные строки высотой не менее 44 px. Экспериментальный раздел «Сообщество ИТИ» остаётся выключенным и скрытым по умолчанию.

В опасной зоне доступна кнопка «Сбросить первое знакомство». После подтверждения она удаляет только отметку завершения onboarding через `resetOnboarding(AsyncStorage)`. Экран первого знакомства появится при следующем запуске приложения; текущие настройки, кэш и прочие пользовательские данные не очищаются. Ошибка сброса показывается через системный alert.

Очистка кэша использует `clearAllCache` и удаляет только кэшированные записи с TTL-конвертом. Настройки, отметка onboarding и другие пользовательские данные сохраняются; ошибки очистки показываются через alert.
