# Проверка обновления интерфейса и уведомлений

## Автоматически

*   `node --test tests/*.test.cjs`
*   `npx expo export --platform all` (только JS/asset export, не native build)
*   `git diff --check`

## На реальном устройстве

1.  **Расписание**: Открыть расписание: текст ниже заголовка, прокручивается за ним. Кнопки «Назад» и «Поделиться» имеют доступную область нажатия; избранное и экспорт работают, экспорт нельзя запускать повторно во время выполнения.
2.  **Меню пары**: Открыть меню пары через долгое нажатие на название: заметка, отправка; посещаемость осталась отдельным действием.
3.  **Новости**: Открыть новости: ввод, очистка, отмена, прокрутка с клавиатурой. Долгое нажатие — отправка и источник, если API действительно передал URL. Загрузка старых страниц не вызывает уведомления о публикациях.
4.  **Карта**: Отказ в геолокации не блокирует карту. Фильтры и маршрут открываются кастомным нижним листом (`NativeSheet`); закрыть кнопкой, свайпом iOS и кнопкой «Назад» Android. На Android интерактивная Google-карта по-прежнему отключена намеренно.
5.  **Заметки/ДЗ**: Редактирование с клавиатурой, предупреждение о несохранённых изменениях, напоминание; учебное событие: нижние поля доступны на небольшом экране.
6.  **Настройки**: Читаемые поверхности в обеих темах, выбор преподавателя/аудитории, быстрый ввод и отмена не возвращают запоздалые результаты; сообщество остаётся скрытым по умо��чанию. Проверить работу переключателей для сплэша легенды и анимации конфетти.
7.  **Уведомления (первый запуск)**: Первый запуск не просит уведомления. Включение в настройках запрашивает разрешение; отказ объясняется, есть переход в системные настройки. Возвращение из системных настроек обновляет состояние.
8.  **Уведомления (поведение)**: При открытом приложении новое событие показывает один внутренний баннер, а не два уведомления. При фоне — системное уведомление, если разрешено. Нажатие из фона/холодного запуска открывает правильный раздел (пока не конкретную пару/новость).
9.  **Напоминания о парах**: Включить/отключить виды напоминаний; ДЗ и события при этом не удаляются. Поздняя загрузка времени звонков не стирает ранее запланированные напоминания.

Б��з сервера push фоновые проверки новостей остаются `best effort` по расписанию ОС; гарантированная доставка при закрытом приложении не реализована. Полезно отдельно проверить `Reduce Transparency`, крупный текст, `VoiceOver`/`TalkBack` и светлую/тёмную тему.
