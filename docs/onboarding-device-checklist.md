# Проверка онбординга на устройстве

Для проверки сбросьте отметку в меню разработчика и полностью перезапустите приложение. Сброс не должен открывать онбординг посреди текущей сессии.

1.  **Обычное движение**: При запуске короткое вступление, конфетти и плавное открытие первой страницы; при возврате из системного диалога разрешений вступление не повторяется.
2.  **«Уменьшение движения»**: Нет конфетти/масштабирования, содержимое сразу доступно. Переключение настройки во время вступления не блокирует экран.
3.  **«Далее» и «Назад»**: Заметное плавное перелистывание в обе стороны, без скачка к целевой позиции; свайпы работают, быстрые нажатия не теряют страницу.
4.  **Нативные стеклянные кнопки iOS 26+**: Остаются настоящими `SwiftUI Button`. Большой системный шрифт и маленький экран не обрезают контент.
5.  **Карточки**: Открыть каждую, проверить информативные строки и подсказку, прокрутку длинного текста, закрытие крестиком/жестом/Android Back. Модальные окна функций/конфиденциальности онбординга реализованы как ограниченные нижние листы (`NativeSheet`), поддерживающие жесты вертикального расширения/сворачивания и закрытие по фону, а не полноэкранные модальные окна.
6.  **Нижняя часть первой страницы**: Версия/сборка мелким читаемым шрифтом, доступное оп��сание конфиденциальности. Не использовать `SECURITY.md` вместо политики.
7.  **Разрешения**: Каждый запрос разрешения — только по явному нажатию. Отказ в календаре не ломает статусы уведомлений/галереи; недоступный метод не выдаёт `TypeError`. Календарь использует корневой объектный API `expo-calendar` с `writeOnly: false` для полного доступа к календарю, необходимого для экспорта в существующий календарь.
8.  **Галерея**: Выдача `add-only`, отказ, повтор после настроек, PNG полного выбранного расписания через меню экспорта. Не запрашивается чтение всей библиотеки. Галерея использует доступ только для добавления `expo-media-library` и `Asset.create()`.
9.  **Завершение онбординга**: Завершить или пропустить, перезапустить: онбординг не появляется повторно; очистка кэша также не сбрасывает отметку.

Автоматические `unit`/`VM`-тесты и `JS bundle export` не заменяют эти проверки геометрии, анимаций, `EventKit` и `Photos` на iPhone/iPad/Android.
