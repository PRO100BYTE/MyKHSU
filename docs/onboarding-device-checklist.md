# Проверка знакомства на устройстве

Для проверки сбросить отметку в меню разработчика и полностью перезапустить приложение. Сброс не должен открывать знакомство посреди текущей сессии.

1. Обычное движение: при запуске короткое вступление, конфетти и плавное открытие первой страницы; при возврате из системного диалога разрешений вступление не повторяется.
2. «Уменьшение движения»: нет конфетти/масштабирования, содержимое сразу доступно. Переключение настройки во время вступления не блокирует экран.
3. «Далее» и «Назад»: заметное плавное перелистывание в обе стороны, без скачка к целевой позиции; свайпы работают, быстрые нажатия не теряют страницу.
4. Нативные стеклянные кнопки iOS 26+ остаются настоящими SwiftUI Button. Большой системный шрифт и маленький экран не обрезают контент.
5. Карточки: открыть каждую, проверить информативные строки и подсказку, прокрутку длинного текста, закрытие крестиком/жестом/Android Back.
6. Нижняя часть первой страницы: версия/сборка мелким читаемым шрифтом, доступное описание конфиденциальности. Не использовать SECURITY.md вместо политики.
7. Каждый запрос разрешения — только по явному нажатию. Отказ в календаре не ломает статусы уведомлений/галереи; недоступный метод не выдаёт TypeError.
8. Галерея: выдача add-only, отказ, повтор после настроек, PNG полного выбранного расписания через меню экспорта. Не запрашивается чтение всей библиотеки.
9. Завершить или пропустить, перезапустить: знакомство не появляется повторно; очистка кэша также не сбрасывает отметку.

Автоматические unit/VM-тесты и JS bundle export не заменяют эти проверки геометрии, анимаций, EventKit и Photos на iPhone/iPad/Android.
