# Верхняя панель

На iOS `HeaderToolbar` сохраняет системный материал GlassView, но группирует действия раздела в системный ActionSheetIOS. Это не UINavigationBar и не UIMenu: используется настоящий системный action sheet, а стеклянная оболочка остаётся React-компонентом.

- Название ограничено одной строкой, чтобы кнопки не вытесняли его на узком экране.
- Назад и меню действий имеют область нажатия 44×44 и подписи доступности.
- Избранное, экспорт, сведения о кэше и фильтры доступны по кнопке многоточия; выполняющийся экспорт недоступен для повторного запуска.
- Системный iOS таббар остаётся отдельным нативным UITabBarController.
- Панель остаётся поверх контента; текстовые экраны сохраняют прокручиваемый верхний отступ.

Проверить на устройстве: узкий экран, большой шрифт, возврат из подраздела, меню при экспорте, фильтры карты и светлая/тёмная тема. Системные разрешения и закрытие листов не проверяются экспортом JS-бандла.
