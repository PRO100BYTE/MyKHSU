# Поиск и контекстные действия

## Поле поиска

`components/SearchField.js` — переиспользуемое управляемое поле React Native `TextInput`, **не** UIKit `UISearchController` и не нативная строка поиска навигационного контроллера.

API default-экспорта: `value` (строка), `onChangeText(text)`, необязательные `onCancel()`, `placeholder`, `theme`, `accentColor` (ключи существующих палитр). Отмена очищает запрос, снимает фокус, закрывает клавиатуру, затем вызывает `onCancel`. Очистка не снимает фокус. Кнопка поиска на клавиатуре закрывает её. Нет autoFocus, повторного захвата фокуса или перехвата системной кнопки «Назад». Кнопки подписаны для screen reader, размер очистки — 44 × 44.

Новости используют поле для локальной фильтрации **только загруженных** новостей, без дополнительных сетевых запросов. Пробелы по краям запроса игнорируются. Прокрутка закрывает клавиатуру, действия доступны при открытой клавиатуре. Поиск преподавателей/аудиторий в настройках не перенесён: ScheduleScreen не содержит этих полей, и изменение их загрузки/выбора выходит за рамки этой минимальной интеграции.

## Действия

`utils/contextActions.js`: `showContextActions({ title, actions: [{ label, onPress }] })`. iOS использует системный `ActionSheetIOS`, Android — `Alert` с отменой и закрытием вне диалога. Это системное меню действий, **не** UIKit context-menu preview. Ошибки действий (включая Promise rejection) показывают понятное сообщение. Не добавлены зависимости.

- Нажатие/долгое нажатие новости открывает меню; обычное нажатие делает его доступным без жеста удержания. Поделиться отправляет текст и доступный URL через системный Share. «Открыть источник» доступно только для явного HTTP(S) URL из `url`, `link`, `source_url`; источник не выдумывается по ID новости.
- Долгое нажатие названия занятия открывает «Заметка» / «Поделиться». Дополнительная кнопка с многоточием находится в существующей панели действий занятия. Посещаемость, её циклическое переключение и существующая кнопка заметок не изменены; родительская карточка не перехватывает нажатия вложенных кнопок.
- Отмена ничего не изменяет; действия не удаляют данные и не выполняются автоматически.

## Проверка

1. Открыть новости, ввести запрос с пробелами, проверить пустой результат и очистку; проверить отмену/возврат клавиатуры, системную кнопку «Назад» Android и прокрутку.
2. Проверить VoiceOver/TalkBack: поле, очистка, отмена, новость и кнопка меню занятия доступны.
3. На iOS и Android открыть меню новости с URL и без URL; проверить отмену, Share, возврат в приложение и ошибку открытия ссылки.
4. Открыть расписание студента, преподавателя и аудитории; удержать название занятия, открыть заметку и Share. Проверить прежнее переключение посещаемости и кнопку заметок, дни/недели и обновление.
5. Проверить новости из кэша/без сети, светлую/тёмную тему, увеличенный шрифт и iPad.

Автоматическая проверка утилиты: `node tests/contextActions.test.cjs`. Проверка синтаксиса Babel не заменяет тест на устройстве.
