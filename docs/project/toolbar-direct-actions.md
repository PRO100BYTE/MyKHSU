# Прямые действия на панели инструментов

`HeaderToolbar` на iOS сохраняет материал `GlassView` и использует нативные `UIMenu` через `@react-native-menu/menu` для дополнительных действий. Однако, некоторые ключевые действия доступны непосредственно на панели инструментов, без необходимости открывать меню.

## Прямые действия

*   **Избранное расписание / Фильтры карты**: Основное действие видно непосредственно на панели инструментов. Для расписания это может быть индикатор избранного расписания, а для карты — счётчик активных фильтров.
*   **Экспорт расписания**: Кнопка «Поделиться» для экспорта расп��сания доступна напрямую. Многоточия для дополнительных действий в этом разделе нет.
*   **Сведения о кэше**: Доступны через отдельную иконку статуса размером 22 в акцентном цвете. Отсутствие сети различается формой и доступной подписью.

## Поведение

*   Кнопки «Назад» и действия имеют область нажатия 44×44; длинный заголовок занимает оставшуюся ширину и не переносится.
*   Android сохраняет прежнюю панель инструментов.
*   Если нативный модуль `@react-native-menu/menu` не зарегистрирован (например, после OTA/Metro reload без пересборки), вместо нативного меню показываются обычная кнопка и системный `action sheet`.

## Проверка

*   **Прямые действия**: Убедиться, что избранное расписание/фильтры карты, экспорт расписания и сведения о кэше доступны непосредственно на ��анели инструментов без открытия дополнительного меню.
*   **Размер кнопок**: Проверить, что кнопки имеют область нажатия 44×44.
*   **Android**: Убедиться, что Android сохраняет свою прежнюю панель инструментов.
*   **Fallback**: Проверить, что при отсутствии нативного модуля `@react-native-menu/menu` отображается корректный `fallback` (обычная кнопка и системный `action sheet`).
