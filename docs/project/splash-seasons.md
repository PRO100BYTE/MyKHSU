# Сезонные эффекты сплэш-экрана

`components/SeasonalSplashEffects.js` содержит логику анимации конфетти-эмодзи для сплэш-экрана, которая адаптируется к сезону/празднику. Эти эффекты располагаются между фоном и элементами логотипа/текста сплэш-экрана.

## Принципы работы

*   **Адаптация к сезону/пр��зднику**: Компонент определяет текущий сезон или праздник на основе даты и применяет соответствующие эмодзи для конфетти.
*   **Непрерывная анимация**: Анимация конфетти непрерывная, с рандомизированными начальными точками в верхней части экрана, полностью падает за пределы экрана и имеет регулируемую скорость.
*   **Расположение**: Эффекты располагаются между фоном и элементами логотипа/текста, создавая многослойный визуальный эффект.

## Конфигурация

*   **Эмодзи**: Набор эмодзи для каждого сезона/праздника определяется в `utils/constants.js`.
*   **Скорость**: Скорость падения конфетти регулируется для создания желаемого визуального эффекта.
*   **Переключатель**: В настройках внешнего вида (`components/AppearanceSettingsSheet.js`) добавлен переключатель для откл��чения анимации конфетти.

## Проверка

*   **Сезонность**: Проверить, что конфетти адаптируется к текущему сезону/празднику (например, снежинки зимой, листья осенью).
*   **Анимация**: Убедиться, что анимация непрерывная, с рандомизированными начальными точками и полным падением за пределы экрана.
*   **Расположение**: Проверить, что конфетти находится между фоном и логотипом/текстом.
*   **Переключатель**: Убедиться, что переключатель в настройках корректно включает/отключает анимацию.
