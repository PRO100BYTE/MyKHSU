# Конфиденциальность: текущая реализация

Официальная политика конфиденциальности опубликована по адресу: `https://myiti.pro100byte.ru/privacy-policy`.

Экран онбординга показывает локальное описание обработки данных и разрешений в дополнение к официальной политике. Это описание фактической реализации и не заменяет опубликованную политику.

**Проверенные факты:**

*   Регистрация учётной записи для использования приложения не требуется.
*   Настройки учебного профиля, заметки, посещаемость и кэш хранятся на устройстве (`SecureStore`/`AsyncStorage`).
*   Приложение обращается к внешнему API расписания/новостей и картографическим сервисам; нельзя обещать, что все данные всегда остаются на устройстве.
*   Геолокация опциональна; разрешение календаря используется для экспорта, `Photos` — для добавления изображения расписания без чтения библиотеки.
*   `App.js` инициализирует Sentry автоматически с `sendDefaultPii: true`, `replaysSessionSampleRate: 0.1` и `replaysOnErrorSampleRate: 1`. Настроены отчёты об ошибках, технический контекст и выборочные записи взаимодействия. Встроенного переключат��ля отключения диагностики сейчас нет. Настройка не доказывает, что `replay` поддерживается/записывается на каждой платформе и сборке.
*   Поэтому текст «не содержит персональных данных» в About исправлен. Настройки самого Sentry этим изменением не менялись.

Перед релизом владелец должен согласовать текст политики с фактическими сервисами/сроками хранения и оценить необходимость явного согласия и управления диагностикой. Не приписывать этим изменениям юридическую проверку.
