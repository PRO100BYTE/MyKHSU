# Установка и запуск бэкенда Мой ИТИ ХГУ

Этот документ описывает шаги, необходимые для установки, настройки и запуска бэкенд-сервиса "Мой ИТИ ХГУ" локально.

## Требования

Перед началом убедитесь, что у вас установлены:

*   **Node.js:** Версия 18.x или выше.
*   **npm:** (поставляется с Node.js) или Yarn.
*   **Git:** Для клонирования репозитория.

## 1. Клонирование репозитория

Сначала клонируйте репозиторий бэкенда:

```bash
git clone https://github.com/PRO100BYTE/MyKHSU-Backend.git
cd MyKHSU-Backend
```

## 2. Установка зависимостей

Установите все необходимые зависимости проекта:

```bash
npm install
# или
yarn install
```

## 3. Настройка переменных окружения

Бэкенд использует переменные окружения для конфигурации. Создайте файл `.env` в корневой директории проекта, скопировав содержимое из `.env.example` и заполнив его своими значениями.

```bash
cp .env.example .env
```

Откройте файл `.env` и настройте следующие переменные (пример):

```ini
PORT=3000
NODE_ENV=development
JWT_SECRET=your_super_secret_jwt_key
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin_password
DATABASE_PATH=./data/pairs.sqlite
USERS_DATABASE_PATH=./data/users.sqlite
LOG_FILE_PATH=./logs/server.log

# Sentry (опц��онально)
SENTRY_DSN=
SENTRY_ENVIRONMENT=development
```

**Важно:**

*   `JWT_SECRET`: Используйте длинную, случайную и сложную строку для продакшн-среды.
*   `ADMIN_USERNAME`, `ADMIN_PASSWORD`: Используются для создания первого администратора. **Обязательно измените их для продакшн-среды.**
*   `DATABASE_PATH`, `USERS_DATABASE_PATH`: Указывают на файлы SQLite баз данных. Убедитесь, что директория `data/` существует.

## 4. Инициализация базы данных

При первом запуске бэкенд автоматически создаст необходимые таблицы в SQLite базах данных, если они не существуют. Однако, для создания начального пользователя-администратора вы можете использовать скрипт:

```bash
node scripts/create-admin.js
```

Этот скрипт создаст пользователя с логином и паролем, указанными в `.env` (`ADMIN_USERNAME`, `ADMIN_PASSWORD`).

## 5. Запуск сервера

Запустите бэкенд-сервис:

```bash
npm start
# или
yarn start
```

Сервер будет запущен на порту, указанном в переменной `PORT` (по умолчанию 3000). Вы увидите сообщения в консоли о запуске сервера и подключении к базам данных.

## 6. Доступ к API

После запуска сервера вы можете обращаться к API по адресу `http://localhost:PORT` (например, `http://localhost:3000`).

Подробное описание доступных эндпоинтов API можно найти в разделе [API](api.md).

## Дополнительные скрипты

*   **`npm run build-frontend`:** Сборка фронтенд-приложений (админ-панели и веб-версии).
*   **`node scripts/manage-users.js`:** Скрипт для управления пользователями (создание, удаление, изменение пароля).
*   **`node scripts/sync-build-info.js`:** Скрипт для синхронизации информации о сборке.
