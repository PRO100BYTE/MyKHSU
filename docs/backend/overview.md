# Обзор бэкенда Мой ИТИ ХГУ

Этот документ предоставляет общий обзор бэкенд-сервиса для приложения "Мой ИТИ ХГУ". Бэкенд разработан для обеспечения стабильной и масштабируемой работы мобильного приложения, предоставляя данные о расписании, новостях, пользователях и других функциях.

## Цели проекта

Основные цели бэкенда включают:

*   **Предоставление данных:** Обеспечение доступа к актуальной информации о расписании занятий, новостях университета, информации о преподавателях и аудиториях.
*   **Управление пользователями:** Обработка аутентификации, авторизации и управления профилями пользователей.
*   **Синхронизация данных:** Поддержка механизмов для обновления и синхронизации данных с внешними источниками (если применимо).
*   **Администрирование:** Предоставление API для панели администратора для управления контентом и пользователями.

## Используемые технологии

Бэкенд построен на следующих ключевых технологиях:

*   **Node.js:** Среда выполнения JavaScript для серверной части.
*   **Express.js:** Веб-фреймворк для Node.js, используемый для построения RESTful API.
*   **SQLite:** Легковесная реляционная база данных, используемая для хранения данных. Выбрана за простоту развёртывания и использования.
*   **`better-sqlite3`:** Высокопроизводительный драйвер SQLite для Node.js.
*   **`jsonwebtoken` (JWT):** Для аутентификации и авторизации пользователей.
*   **`argon2`:** Для безопасного хеширования паролей.

## Архитектура

Бэкенд следует модульной архитектуре, разделяя функциональность на следующие основные компоненты:

*   **`src/index.js`:** Главный файл приложения, инициализирующий сервер Express, подключающий маршруты и middleware.
*   **`src/routes/`:** Директория, содержащая определения всех API-маршрутов.
*   **`src/db/`:** Модули для взаимодействия с базой данных SQLite.
*   **`src/middleware/`:** Функции middleware для обработки запросов (например, аутентификация, валидация).
*   **`src/utils/`:** Вспомогательные утилиты и функции.
*   **`src/config.js`:** Конфигурация приложения.

Более подробную информацию об архитектуре можно найти в разделе [Архитектура бэкенда](architecture.md).
