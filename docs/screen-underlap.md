# Прокрутка под плавающим заголовком

`components/ScreenScrollView.js` — совместимая с React Native `ScrollView` обёртка для корневого содержимого экранов. Импорт: `import ScrollView from './ScreenScrollView'`.

На iOS вертикальная корневая прокрутка получает `contentInset.top = safeAreaInsets.top + 62` и начальный `contentOffset.y = -contentInset.top`. Первый элемент сразу виден ниже плавающего заголовка, но при прокрутке проходит под ним. Это нативный inset, а не неподвижный верхний padding. Автоматическая коррекция inset и индикаторов отключена; верхний inset индикатора синхронизирован с заголовком. Обёртка должна находиться внутри `SafeAreaProvider`, а контейнер экрана — занимать всю доступную высоту без дополнительного отступа под заголовок.

## API

- Все обычные props `ScrollView` и `ref` передаются нативному компоненту.
- `underlap` (по умолчанию `true`): `false` отключает добавление inset, например для модальных окон.
- `headerInset`: полная высота верхнего перекрытия; по умолчанию `safeAreaInsets.top + 62`.
- Переданный `contentInset.top` добавляется к высоте перекрытия; остальные поля сохраняются.
- Переданный `contentOffset` имеет приоритет над начальным отрицательным смещением.
- `scrollIndicatorInsets.top` также добавляется к высоте перекрытия.
- На Android/web, для `horizontal` и для вложенных обёрток inset не добавляется. Контекст вложенности предотвращает двойной верхний отступ.

Переведены настройки и их подразделы, расписание, новости, корневые прокрутки раздела первокурсника, сообщество и список корпусов. У списка корпусов поиск и счётчик включены в общую прокрутку, чтобы они не оставались под заголовком. Отступы содержимого первокурсника перенесены из `style` в `contentContainerStyle`, чтобы viewport не обрезался раньше плавающего заголовка.

`MapScreen` использует полноэкранный `MapView`: после снятия верхнего padding в `App.js` карта сама проходит под заголовком. Единственный `ScrollView` карты находится в нижней панели фильтров, поэтому остаётся нативным без верхнего inset. Аналогично не меняются самостоятельные модальные окна (включая свободные аудитории).

## Ручная проверка

1. На iPhone с вырезом открыть новости: поиск виден сразу; при прокрутке карточки проходят под заголовком, pull-to-refresh работает.
2. Проверить первокурснику, звонки, глоссарий, сообщества и корпуса: первый элемент читаем, низ списка доступен, поиск корпусов прокручивается вместе со списком.
3. Открыть карту и фильтры: карта полноэкранная, в панели фильтров нет лишнего верхнего отступа.
4. Проверить Android/web: дополнительный inset не применяется.
5. Проверить вложенную горизонтальную прокрутку, `underlap={false}`, пользовательские inset и `ref.scrollTo`.
