# Snake в меню разработчика

Мини-игра открывается из `DeveloperMenuScreen` и не меняет расписание, карту или настройки приложения.

- Поле — ограниченная сетка 16×16; еда выбирается только из свободных клеток.
- Движение обрабатывается чистым движком `utils/snakeEngine.cjs`: столкновения со стеной/телом переводят игру в состояние окончания, а кнопки и быстрые свайпы используют очередь направления без разворота на 180°.
- Таймер существует только пока модальное окно видно и приложение активно. При уходе в фон он очищается; при возврате запускается только для уже начатой игры.
- Размер поля адаптируется к ширине экрана. Кнопки управления имеют область 48×48 dp и используют текущую тему Liquid Glass, акцент и Montserrat.
- Достижение `snake_champion` при 30 очках сохраняется через существующую систему достижений.

Проверка чистой логики: `npm test` (включает `tests/snakeEngine.test.cjs`).
