# Совместимость меню верхней панели

Красная заглушка с вопросительным знаком и `Unimplemented` означает, что React Native не нашёл реализацию нативного view в установленном бинарнике. Для `MenuView` это возможно после OTA/Metro reload без пересборки приложения с `@react-native-menu/menu`.

`HeaderToolbar` проверяет `UIManager.hasViewManagerConfig('MenuView')` до отрисовки. Если view отсутствует, показывается обычная кнопка Ionicons и рабочий системный action sheet. Если зарегистрирован — привязанное к кнопке нативное меню. Это не исправление отсутствующего модуля в бинарнике: для оригинального popup требуется нативная пересборка с autolinking/Pods.

Проверить обе сборки: без модуля нет красной заглушки и доступен экспорт; с модулем меню раскрывается возле кнопки. Отключённый экспорт не запускается ни в одной ветке. UIKit/Fabric runtime нужно подтвердить на устройстве; JS export не доказывает регистрацию native view.
